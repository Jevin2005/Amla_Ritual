# Specimen Collection botanical assets

Generated for the NatureMist Specimen Collection section with the built-in `image_gen` tool on 2026-10-17. Each asset was generated separately with `transparent_background: true`; no complete reference screenshot was embedded into the website.

Final assets are 900 × 675 WebP images, optimized from the generated PNG originals with Sharp at quality 88 and alpha quality 100. Original transparency is preserved. The generated images were visually inspected for subject, composition, background transparency, and absence of text. These are faithful botanical interpretations of the provided reference, not exact extractions; leaf arrangement, fruit/pod shape and lighting differ in small details.

The original PNGs remain in the tool's generated-images directory. Website assets are stored here, so the website does not depend on that external directory.
