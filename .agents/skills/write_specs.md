# Skill: Write a technical specification

## Objective

Turn a product request into an implementation-ready specification for the existing NatureMist frontend.

## Output

Write `docs/specifications/technical-specification.md` with:

1. Outcome and user value.
2. In-scope and out-of-scope behavior.
3. Routes, components, data flow and server/client boundaries.
4. Responsive, accessibility, performance and SEO acceptance criteria.
5. External integrations, environment variables and data-safety constraints.
6. Validation and release criteria.
7. Clearly marked assumptions, placeholders and decisions requiring approval.

Use the established Next.js and Sites stack unless the user explicitly approves a migration. Ask for approval before implementation when the specification introduces a material product, payment, privacy or infrastructure decision.
